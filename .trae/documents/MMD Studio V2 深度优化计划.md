## 问题总结

根据用户反馈和错误日志，需要解决以下7个问题：

### 1. 修复 RenderEngine 错误
**错误**: `Cannot read properties of undefined (reading 'Color')`
**原因**: `clearScene()` 中使用了 `this.THREE.Color`，但 `this.THREE` 可能未初始化
**解决方案**: 
- 在 `clearScene()` 中添加检查，确保 `this.THREE` 已初始化
- 或者使用原生方式设置背景色

### 2. 统一所有资源交互逻辑
**问题**: 已加载资源的加号按钮、可加载资源的拖动、已加载资源的拖动，三者交互不一致
**解决方案**:
- 统一所有交互入口，都调用相同的 `handleAddToScene` 函数
- 无论点击"+"按钮还是拖放，效果都一致
- 时间轴的拖放也使用相同的逻辑

### 3. 修复四种场景的3D渲染加载
**问题**: 纯色场景、图片场景、视频场景、3D场景的渲染有问题
**解决方案**:
- 修复 `clearScene()` 中的 `this.THREE` 未定义问题
- 确保场景切换时正确清理和加载
- 添加场景类型判断和相应处理

### 4. 优化播放渲染逻辑
**问题**: 播放和渲染逻辑需要优化
**解决方案**:
- 检查 `updateAnimation` 循环
- 确保动作、表情、场景都能正确播放
- 优化渲染性能

### 5. 界面布局调整
**要求**: 
- 时间轴上移
- 中间预览模块变小40%
- 选择资源界面和右边设置向上移
**解决方案**:
- 修改 CSS 布局，调整各面板高度比例
- 使用 flex 布局重新分配空间

### 6. 深度优化操作方法
**要求**: 适配加载渲染
**解决方案**:
- 简化操作流程
- 自动处理资源依赖（如先加载角色再加载动作）
- 优化错误提示

### 7. 时间轴显示优化
**要求**:
- 每一格变小一点
- 同类型块之间可以有间隔（留白时间）
**解决方案**:
- 调整时间轴缩放比例
- 支持片段之间的间隙显示

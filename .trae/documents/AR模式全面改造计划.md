### 2. 动作播放功能修复

**问题诊断：**
- VRM动画需要使用 `vrm.humanoid` 来播放
- 当前使用普通 `AnimationMixer` 可能无法正确绑定骨骼

**修复方案：**
- 使用 `@pixiv/three-vrm` 的 `VRMAnimationLoaderPlugin` 正确加载VRMA
- 使用 `vrm.humanoid` 的 `normalizedHumanBonesRoot` 作为动画根对象
- 添加动画混合（crossfade）功能
- 添加动作预览功能

### 3. 时间轴功能修复与完善

**修复内容：**
- 修复时间轴播放逻辑，与摄像头模式保持一致
- 添加动作节点拖拽调整位置
- 添加过渡动画（blend）支持
- 添加时间轴缩放和滚动
- 添加节点复制/粘贴功能

**新增功能：**
- 时间轴循环播放
- 动作速度调整
- 动作反转播放

### 4. AR技术可实现功能

**立即可实现：**
- **手势识别** - 检测用户手势触发动作
- **语音控制** - 语音命令控制角色
- **多人AR** - 多个用户在同一空间看到同一角色
- **遮挡检测** - 角色被真实物体遮挡
- **光照估计** - 根据环境光调整角色光照
- **面部追踪** - 角色看向用户面部方向

**有趣的功能：**
- **AR拍照** - 角色自动摆姿势配合拍照
- **舞蹈模式** - 角色跟随音乐节奏跳舞
- **互动游戏** - 与角色进行简单互动（接球、猜拳等）
- **路径行走** - 角色沿指定路径行走
- **表情捕捉** - 用户表情同步到角色

### 6. 跟随模式优化

**卡顿优化方案：**
- 使用 `lerp` 平滑插值代替直接设置位置
- 降低跟随更新频率（每2-3帧更新一次）
- 添加跟随阈值（只有移动超过一定距离才更新）
- 使用 Web Worker 处理位置计算

**跟随模式改进：**
- 添加"平滑跟随"和"即时跟随"两种模式
- 添加跟随距离限制（角色不会离摄像头太远）
- 添加自动旋转（角色始终面向摄像头）

## 问题分析与改进方案

### 1. 触摸模式问题
**原因**：
- `event.stopPropagation()` 阻止事件冒泡
- 双指缩放逻辑有问题
- 触摸和鼠标事件重复处理

**改进方案**：
- 移除不必要的 `stopPropagation()`
- 使用 `touch-action: none` CSS禁用默认触摸行为
- 统一使用指针事件或触摸事件

---

### 2. MMD播放位置错误
**原因**：
- hips骨骼位置计算错误，叠加了角色位置和MMD偏移
- 初始位置保存时机有问题

**改进方案**：
```javascript
// 使用相对于初始位置的偏移
if (boneName === 'hips') {
  const baseY = mmdInitialHipsPosition.current?.y || position[1]
  bone.position.set(
    position[0] + px,
    baseY + py,  // 使用保存的初始位置作为基准
    position[2] + pz
  )
}
```

---

### 3. 新增涩涩动作页签
**方案**：
- 新增"涩涩"分类（20个动作）
- 动作包括：妩媚、诱惑、撩发、咬唇、扭腰等
- 使用粉色主题色区分

---

### 4. 播放列表问题
**原因**：
- 回调函数未正确绑定
- 状态更新异步导致时机不一致

**改进方案**：
- 使用 `useRef` 同步访问播放列表状态
- 添加副作用监听播放列表动作变化
- 添加播放状态视觉反馈

---

### 5. 交互模型按钮重做
**现状问题**：
- 眼睛、手指、面具、设置按钮功能不明确
- 移动端触摸反馈不足
- 缺少 `onTouchCancel` 处理

**改进方案**：
- 重新设计按钮图标和功能：
  - 👁️ 视角切换（自由/跟随/固定）
  - 👆 交互模式（触摸角色触发动作）
  - 🎭 表情面板（快速切换表情）
  - ⚙️ 设置面板
- 添加长按提示功能说明
- 增大按钮尺寸至48px以上

---

### 6. 骨骼编辑器问题
**原因**：
- 依赖全局变量 `window.vrmModels`
- 桌面端缺少鼠标事件支持
- 骨骼旋转没有限制
- 选中骨骼没有视觉反馈

**改进方案**：
- 通过props传递VRM模型引用
- 添加鼠标事件支持（mousedown/mousemove/mouseup）
- 添加旋转角度限制（±90度）
- 3D场景中高亮显示选中骨骼
- 添加撤销/重做功能

---

### 7. 从人的角度分析更好用的方案

#### 使用场景分析：
1. **拍照分享场景**：用户想快速拍一张好看的AR照片
2. **创作场景**：用户想制作一段角色动画
3. **互动场景**：用户想与虚拟角色互动

#### 改进方向：
1. **简化操作流程**：
   - 一键拍照（无需先选择动作）
   - 智能推荐动作（根据场景推荐）
   - 快速分享（一键分享到社交平台）

2. **增强沉浸感**：
   - 添加音效反馈
   - 角色眼神跟随用户
   - 环境互动（角色会对环境做出反应）

3. **降低学习成本**：
   - 操作提示气泡
   - 手势教学动画
   - 功能引导视频

4. **提升创作效率**：
   - 动作收藏夹
   - 自定义动作组合
   - 场景模板

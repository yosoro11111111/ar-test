## 1. 资源库重构

### 问题
当前只支持5种资源类型，需要扩展支持更多类型

### 改造方案
扩展资源类型支持：
- **角色** (models/)
- **道具** (object/)
- **场景** (scene/) - 支持GLB模型、纯色、视频、图片背景
- **动作** (motion/)
- **音乐** (music/)
- **特效** (effects/) - 粒子、光照等
- **摄像机预设** (camera/)
- **材质** (materials/)

更新 ResourceManager 解析更多资源类型，并在 assets.json 中定义。

## 2. 时间轴逻辑重构（核心）

### 2.1 轨道层级结构（从上到下）

```
┌─────────────────────────────────────┐
│ 场景轨道 (Scene Track)               │ ← 最顶层，只能有一个
│ - 支持多个场景片段                    │
│ - 场景类型: GLB/纯色/视频/图片        │
├─────────────────────────────────────┤
│ 摄像机轨道 (Camera Track)            │ ← 控制视角
│ - 多个摄像机片段                     │
│ - 可在预览区调整位置                  │
├─────────────────────────────────────┤
│ 角色1 - 动作轨道                      │ ← 每个角色一行
│ 角色1 - 表情轨道                      │ ← 同角色不同类别
│ 角色1 - 道具绑定轨道                  │ ← 角色绑定的道具
├─────────────────────────────────────┤
│ 角色2 - 动作轨道                      │ ← 新角色添加在最下面
│ 角色2 - 表情轨道                      │
├─────────────────────────────────────┤
│ 独立道具轨道                          │ ← 不绑定角色的道具
├─────────────────────────────────────┤
│ 音乐轨道 (Music Track)               │ ← 最底层
└─────────────────────────────────────┘
```

### 2.2 轨道规则

**场景轨道**：
- 只有一条轨道
- 可添加多个场景片段（切换场景）
- 片段类型：GLB模型/纯色/视频/图片

**摄像机轨道**：
- 只有一条轨道
- 可添加多个摄像机片段
- 每个片段定义摄像机位置和移动路径
- 在预览区可视化调整摄像机位置

**角色轨道组**：
- 添加角色时自动创建一组轨道
- 包含：动作轨道、表情轨道、道具绑定轨道
- 同角色不能有重复类型的轨道
- 新角色轨道组添加在最下面

**音乐轨道**：
- 只有一条轨道
- 可添加多个音乐片段（背景音乐/音效）

### 2.3 拖放逻辑

```
拖拽角色 → 自动创建角色轨道组（动作+表情+道具）
拖拽动作 → 必须放到角色的动作轨道上
拖拽表情 → 必须放到角色的表情轨道上
拖拽道具 → 可选择：绑定到角色/独立道具轨道
拖拽场景 → 放到场景轨道
拖拽摄像机预设 → 放到摄像机轨道
拖拽音乐 → 放到音乐轨道
```

### 2.4 片段功能增强

**片段操作**：
- 拖拽调整位置
- 拖拽边缘调整时长
- 右键菜单：删除/复制
- 双击编辑属性

**片段属性（右侧面板动态显示）**：
- 场景片段：类型、颜色/路径、混合模式
- 摄像机片段：位置、目标点、FOV、移动曲线
- 动作片段：速度、循环、淡入淡出
- 表情片段：强度、混合时长
- 音乐片段：音量、淡入淡出

## 3. 右侧面板动态化

根据选中的时间轴片段类型，右侧面板显示不同的设置：

| 选中对象 | 右侧面板显示 |

| 摄像机片段 | 摄像机设置（位置、目标、FOV、曲线） |

| 表情片段 | 表情设置（强度、混合） |
| 音乐片段 | 音频设置（音量、淡入淡出） |
| 预览区角色 | 变换设置（位置、旋转、缩放） |

## 4. 实时渲染系统

### 渲染流程
```
1. 时间轴准备好后（有场景+角色）
   ↓
2. 点击播放按钮
   ↓
3. 实时渲染每一帧
   - 根据时间轴计算当前场景
   - 计算角色动作（插值）
   - 计算摄像机位置
   - 渲染到预览区
   ↓
4. 播放过程中可暂停调整
   ↓
5. 导出时后台逐帧渲染
```

### 渲染引擎优化
- 使用 requestAnimationFrame
- 动作插值计算
- 摄像机路径插值
- 场景过渡混合

# MMD Studio 界面重设计方案

## 当前问题
1. 预览区域太大，时间轴太小
2. 界面不够美观
3. 缺少多人调整功能

## 新设计方案

### 布局调整
```
┌─────────────────────────────────────────────────────────┐
│ 顶部工具栏 (简化)                                        │
├──────────┬─────────────────────────────┬────────────────┤
│          │                             │                │
│  左侧    │      预览区 (缩小)           │    右侧       │
│  资源    │      40% 高度                │    属性       │
│  面板    │                             │    面板       │
│  20%     │                             │    20%        │
│          │                             │                │
├──────────┴─────────────────────────────┴────────────────┤
│                                                         │
│  时间轴区域 (放大)                                       │
│  50% 高度                                               │
│  - 支持多角色轨道                                        │
│  - 轨道可折叠/展开                                       │
│  - 片段拖拽编辑                                          │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 具体改进

#### 1. 预览区域 (缩小到40%高度)
- 使用老代码的 previewArea 样式
- 添加画布比例控制 (16:9, 9:16, 1:1)
- 添加缩放控制
- 简化工具栏

#### 2. 时间轴区域 (放大到50%高度)
- 参考老代码 Timeline 组件
- 支持多角色轨道显示
- 每个角色可以有多个轨道(动作、位置、表情)
- 轨道可折叠
- 片段可拖拽调整

#### 3. 左侧资源面板
- 简化设计
- 快速添加按钮
- 资源分类显示

#### 4. 右侧属性面板
- 参考老代码样式
- 根据选中对象动态显示
- 支持多选批量调整

#### 5. 多人调整功能
- 在时间轴上显示多个角色
- 每个角色独立轨道组
- 可以同时编辑多个角色
- 角色间可以有交互

### 技术实现
1. 重写 MMDStudio 主布局
2. 重写 Timeline 组件(参考老代码)
3. 优化 CSS 样式(参考老代码的暗色主题)
4. 添加多角色管理

## 当前问题分析

1. **初始化顺序问题** - useMemo 在 project 定义之前使用
2. **操作步骤繁琐** - 需要多次点击才能完成基本设置
3. **交互流程不直观** - 很多功能隐藏在深层菜单中

## 优化方案

### Phase 1: 修复初始化错误
- 调整代码顺序，确保 useMemo 在 project 定义之后使用
- 重构状态管理，避免循环依赖

### Phase 2: 新建项目向导
进入页面时弹出项目设置向导，一步完成基础配置：

**步骤1: 项目信息**
- 项目名称输入
- 项目时长设置（默认60秒）

**步骤2: 画布设置**
- 预设选择（16:9, 9:16, 1:1, 4:3）
- 自定义分辨率
- 背景颜色/图片

**步骤3: 快速添加角色**
- 直接显示角色选择器
- 支持多选
- 预设位置摆放

**步骤4: 完成**
- 自动创建基础轨道
- 进入主界面

### Phase 3: 简化主界面操作

**顶部工具栏优化：**
```
[项目名] [保存💾] [撤销↩️] [重做↪️] [设置⚙️] [导出📤]
```

**左侧边栏 - 快速操作：**
```
🎭 角色    ✨ 特效    📦 道具
🎵 音乐    🎥 摄像机  🖼️ 背景
```
点击直接添加对应轨道

**右侧属性面板：**
- 选中片段时显示编辑面板
- 不选中时显示项目概览

**时间轴优化：**
- 双击空白处快速添加片段
- 右键菜单：复制、删除、编辑
- 拖拽调整时间和时长

### Phase 4: 智能片段创建

**动作片段：**
- 添加时自动弹出动作选择
- 记住上次选择的角色

**摄像机片段：**
- 添加时自动创建起始和结束关键帧
- 默认使用当前视角

**音乐片段：**
- 添加时自动弹出文件选择
- 自动匹配音乐时长

### Phase 5: 一键快捷操作

**快捷键：**
- Space: 播放/暂停
- Ctrl+S: 保存
- Ctrl+Z: 撤销
- Delete: 删除选中
- 双击: 编辑片段

**智能提示：**
- 首次使用显示引导
- 操作提示气泡
- 快捷键提示

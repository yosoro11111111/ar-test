## 目标
重做MMD系统的AR场景录制功能，实现：
1. **录制真实3D场景** - 拍照保存真实场景图片+JSON配置文件，打包导出
2. **导入文件** - 适配时间轴显示，计算位置和录制渲染
3. **摄像头背景** - 拍摄时显示真实摄像头画面

## 现有代码分析
- `ARSceneRecorder.jsx` - AR场景录制UI组件（WebXR模式）
- `ARRecorder.js` - AR录制核心逻辑（平面检测、相机位姿记录）
- `ARSceneIO.js` - 场景包导入导出（ZIP格式）
- 当前使用模拟平面，没有真实摄像头背景

## 实现方案

### 第一阶段：真实场景录制器（新组件）

创建 `RealARSceneRecorder.jsx`：

1. **摄像头访问**
   - 使用 `navigator.mediaDevices.getUserMedia()` 获取摄像头
   - 显示摄像头画面作为背景
   - 支持前后摄像头切换

2. **拍照功能**
   - 捕获摄像头画面为图片（Canvas绘制）
   - 保存图片为base64或文件

3. **3D平面标记**
   - 在摄像头画面上叠加Three.js场景
   - 用户点击画面放置平面标记点
   - 记录平面的3D位置（相对于相机）
   - 支持多个平面（地面、墙面等）

4. **场景数据保存**
   ```json
   {
     "version": "2.0",
     "type": "real-ar-scene",
     "capturedAt": "2024-01-01T00:00:00Z",
     "image": "base64...",
     "planes": [
       {
         "id": "plane_1",
         "type": "floor|wall|custom",
         "position": { "x": 0, "y": 0, "z": -2 },
         "rotation": { "x": -90, "y": 0, "z": 0 },
         "size": { "width": 3, "height": 2 },
         "screenPosition": { "x": 0.5, "y": 0.7 }
       }
     ],
     "camera": {
       "fov": 60,
       "position": { "x": 0, "y": 1.6, "z": 0 }
     }
   }
   ```

5. **打包导出**
   - 使用JSZip打包图片+JSON
   - 导出 `.arscene2` 文件

### 第二阶段：场景导入适配

修改 `ARSceneIO.js`：
1. 支持导入新的 `real-ar-scene` 类型
2. 解析图片和平面数据
3. 转换为内部场景格式

### 第三阶段：时间轴适配

修改 `index.jsx` 中的场景加载逻辑：
1. 识别真实AR场景类型
2. 加载图片作为3D场景背景
3. 根据平面数据计算角色位置
4. 支持在真实场景上放置和移动角色

### 第四阶段：录制渲染

1. **预览模式**
   - 显示真实场景图片作为背景
   - 3D角色在标记的平面上活动
   - 支持调整角色位置

2. **录制模式**
   - 合成3D渲染+背景图片
   - 导出最终视频/图片

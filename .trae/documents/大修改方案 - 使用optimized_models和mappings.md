## 修改计划

### 1. 模型系统改造
**使用 `optimized_models` 文件夹**
- 模型路径改为 `/optimized_models/{name}_optimized.vrm`
- 从 `mappings` 文件夹加载对应的骨骼映射
- 每个模型对应一个 `{modelName}_mapping.json` 文件

### 2. 动作系统改造
**使用 `mappings` 文件夹中的动作对应表**
- 加载模型的动作映射配置
- 动作按钮改为从映射表读取
- 删除底部动作栏（用户要求）

### 3. 底部栏移到右边
**右侧标签式 Dock**
```
┌─────────────────┐
│                 │
│    3D 场景      │  📸 拍照
│                 │  ⭐ 收藏
│                 │  🎨 姿势
│                 │  ⚙️ 设置
│                 │
└─────────────────┘
```
- 垂直排列在右侧
- 标签样式：圆角矩形，图标+文字
- 悬浮时展开标签详情

### 4. 删除底部动作按钮
- 删除底部动作栏组件
- 动作改为通过右侧 Dock 的"动作"标签访问
- 点击后弹出动作选择面板

### 5. 修改教程内容
**简化教程步骤：**
1. 🎮 基础操作 - 点击选中，拖拽移动
2. 🤏 双指缩放 - 放大缩小角色
3. 🎭 动作切换 - 点击右侧动作按钮
4. 📸 拍照分享 - 点击拍照按钮保存图片

### 6. 需要修改的文件
1. `modelList.js` - 更新模型路径和配置
2. `CharacterSystem.jsx` - 加载 optimized_models 和 mappings
3. `AnimeSidebar.jsx` - 改为右侧垂直标签栏
4. `AnimeSidebar.css` - 更新样式
5. `ARSystem.jsx` - 删除底部动作栏，修改教程

请确认此方案后开始实施。

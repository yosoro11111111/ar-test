## 项目概述
对 MMD Studio V2 进行全面功能升级，包括资源管理、时间轴系统、渲染引擎等核心模块。

## 详细任务清单

### 阶段1：资源系统重构
1. **assets.json 自动生成**
   - 扫描 public/models 目录自动生成配置
   - 支持所有 VRM/GLB 文件

2. **左侧资源栏增强**
   - 6个资源类型（角色/道具/场景/动作/音乐/特效）全部支持多选
   - 添加复选框和批量加载按钮
   - 支持批量拖放到时间轴
   - 每个类型添加导入本地文件功能
   - 导入文件显示在"已加载"标签
   - 场景支持：图片/GLB/纯色/视频导入
   - 添加"新建纯色场景"功能

### 阶段2：顶部菜单系统
3. **文件菜单下拉**
   - 新建项目
   - 导入项目
   - 导入资源包
   - 导出资源包（支持选择文件+高压缩）

4. **其他菜单功能**
   - 编辑：撤销/重做/剪切/复制/粘贴
   - 视图：显示/隐藏面板、全屏
   - 渲染：渲染设置、导出视频
   - 帮助：快捷键、关于

### 阶段3：预览界面优化
5. **预览区域调整**
   - 缩小预览界面尺寸
   - 透视/正交/摄像机三种模式切换
   - 实现对应的渲染逻辑

### 阶段4：时间轴系统重构（核心）
6. **时间轴显示优化**
   - 添加时间刻度标尺
   - 片段显示为彩色方块
   - 支持多片段排序显示

7. **片段交互功能**
   - 同轨道内拖动换位置
   - 拖动头部/尾部调整时长
   - 右键菜单：复制、删除

8. **属性系统**
   - 选择片段右侧面板联动
   - 共同属性：开始/结束/持续时间（双向同步）
   - 场景特殊属性：多特效方案
   - 人物特殊属性：位置、路径、速度
   - 音乐特殊属性：变调

### 阶段5：渲染系统
9. **时间轴渲染**
   - 根据时间轴数据实时渲染3D场景
   - 人物动作播放
   - 相机动画
   - 特效渲染

## 技术实现要点
- 使用 React DnD 实现拖拽功能
- 使用 Three.js 进行3D渲染
- 使用 JSZip 实现资源包压缩导出
- 使用 LocalStorage/IndexedDB 存储项目数据

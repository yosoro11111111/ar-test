## MMD Studio V2 完整交互方案

基于对现有代码的分析，我为你设计了一套完整的交互流程，涵盖从资源加载到最终导出的全流程。

---

### 一、资源加载系统改造

#### 1.1 向导界面资源加载（带进度条）

**当前问题**：向导中只是勾选资源，没有实际加载
**改造方案**：
- 步骤3确认时，开始实际加载资源
- 显示加载进度条（每个资源单独进度）
- 加载完成后才进入编辑器
- 已加载资源自动显示在"已加载"视图中

**交互流程**：
```
勾选资源 → 点击"创建项目" → 显示加载进度 → 加载完成 → 进入编辑器
```

#### 1.2 左侧面板"已加载"视图
- 显示实际已加载到内存的资源
- 显示加载状态（加载中/已完成/失败）
- 支持卸载操作

---

### 二、右侧面板图标化改造

**当前问题**：标签显示图标+文字，用户要求只显示图标
**改造方案**：
- 只保留图标按钮
- 鼠标悬停显示Tooltip提示
- 选中状态用高亮边框表示

**标签顺序**：
1. 🎯 变换
2. 🎨 材质  
3. 🎬 动画
4. ⚙️ 物理
5. ✨ 特效

---

### 三、时间轴拖放交互方案（核心）

#### 3.1 拖拽系统架构

**拖拽源（左侧面板）**：
- 角色/道具/场景/动作/音乐资源卡片
- 拖拽时显示半透明预览
- 根据类型判断可放置的轨道

**放置目标（时间轴）**：
- 角色 → 角色轨道
- 道具 → 道具轨道
- 场景 → 场景轨道
- 动作 → 动作轨道（绑定到角色）
- 音乐 → 音乐轨道

#### 3.2 拖拽交互流程

```
1. 从左侧拖拽资源
   ↓
2. 拖拽到时间轴区域，高亮可放置区域
   ↓
3. 放置时：
   - 如果没有对应轨道，自动创建
   - 在放置位置创建片段(Clip)
   ↓
4. 自动加载资源（显示进度）
   ↓
5. 加载完成后，片段变为可播放状态
```

#### 3.3 时间轴片段操作

**基础操作**：
- 点击选中片段
- 拖拽移动位置
- 拖拽边缘调整时长
- 双击编辑属性
- Delete键删除

**片段类型**：
| 类型 | 显示内容 | 可调整时长 |
|------|----------|------------|
| 角色 | 角色名+图标 | ❌ |
| 动作 | 动作名+波形 | ✅ |
| 音乐 | 音乐名+波形 | ✅ |
| 场景 | 场景名+图标 | ❌ |

### 四、完整工作流程设计

#### 阶段1：项目初始化
```
[欢迎界面]
    ↓ 点击"新建项目"
[项目向导 - 步骤1：项目信息]
    - 输入项目名称
    - 选择模板（舞蹈MMD/剧情短片等）
    - 设置分辨率/帧率/时长
    ↓ 下一步
[项目向导 - 步骤2：选择资源]
    - 标签切换：角色/道具/场景/动作
    - 勾选需要的资源
    - 显示已选择摘要
    ↓ 下一步
[项目向导 - 步骤3：确认&加载]
    - 显示项目配置
    - 显示资源列表
    - 点击"创建项目"开始加载
    - 显示加载进度条
    ↓ 加载完成
[进入编辑器]
```

#### 阶段2：场景搭建
```
[左侧面板 - 已加载视图]
    - 拖拽角色到预览区/时间轴
    - 自动创建角色轨道
    
[预览区]
    - 点击选中角色
    - 显示变换控制器（移动/旋转/缩放）
    
[右侧面板 - 变换]
    - 精确调整位置/旋转/缩放
    - 添加关键帧按钮
```

#### 阶段3：动画制作
```
[左侧面板]
    - 拖拽动作到时间轴的角色轨道上
    - 自动创建动作片段
    
[时间轴]
    - 调整动作片段位置
    - 调整动作片段时长（循环/裁剪）
    - 添加多个动作形成序列
    
[右侧面板 - 动画]
    - 调整播放速度
    - 设置循环
    - 调整混合时长
    
[播放控制]
    - 播放/暂停预览
    - 逐帧前进/后退
    - 跳到指定时间点
```

#### 阶段4：实时渲染预览
```
[预览区]
    - 实时播放动画
    - 显示当前帧
    - 支持暂停调整
    
[右侧面板]
    - 材质调整（实时预览）
    - 特效添加（粒子/光照）
    - 物理参数调整
```

#### 阶段5：导出
```
[顶部工具栏 - 导出按钮]
    ↓
[导出设置弹窗]
    - 选择格式（MP4/GIF/序列帧）
    - 设置分辨率
    - 设置码率
    - 选择导出范围（全部/片段）
    ↓
[后台渲染]
    - 显示渲染进度
    - 支持取消
    - 渲染完成提示
    ↓
[保存文件]
```

### 五、关键交互细节

#### 5.1 拖拽视觉反馈
- 拖拽开始时：卡片半透明化
- 拖拽过程中：显示拖拽预览图
- 可放置区域：轨道高亮（绿色边框）
- 不可放置：显示禁止图标

#### 5.2 加载状态指示
- 左侧面板：资源卡片显示加载进度环
- 时间轴：片段显示加载中动画
- 全局：顶部显示总加载进度

#### 5.3 快捷键系统
| 快捷键 | 功能 |
|--------|------|
| Space | 播放/暂停 |
| ←/→ | 前进/后退一帧 |
| Delete | 删除选中片段 |
| Ctrl+Z | 撤销 |
| Ctrl+S | 保存 |

#### 5.4 时间轴缩放
- 滚轮缩放时间轴
- 缩放时保持播放头位置
- 最小缩放：显示全部时长
- 最大缩放：精确到帧

### 六、技术实现要点

1. **拖拽系统**：使用 HTML5 Drag API + 自定义拖拽层
2. **加载管理**：ResourceManager 增加加载队列和进度回调
3. **时间轴渲染**：Canvas 或虚拟列表优化性能
4. **实时预览**：WebGL 渲染 + requestAnimationFrame
5. **后台渲染**：Web Worker + OffscreenCanvas

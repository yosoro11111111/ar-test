## 实施计划

这是一个大型功能增强项目，建议按以下优先级分阶段实施：

### 阶段 1: 紧急修复（1-2天）
1. **修复 console.log 语法错误** - 添加分号解决 ASI 问题
2. **修复资源路径问题** - 确保部署后资源能正常加载
3. **UI 紧凑化** - 调整按钮样式使其完整显示

### 阶段 2: 核心功能完善（3-4天）
4. **编辑菜单功能实现** - 完善撤销、重做、复制、粘贴、删除、全选
5. **视图菜单功能实现** - 视图切换、面板显示/隐藏带勾选状态
6. **工具按钮功能** - 选择工具、手型工具、撤销、搜索
7. **帮助菜单功能** - 快捷键、使用文档、关于对话框

### 阶段 3: 右侧面板强化（3-4天）
8. **变换属性实时编辑** - 位置/旋转/缩放输入框，实时渲染
9. **模型朝向和位置选择** - 添加朝向设置和预览区位置选择功能
10. **场景特效系统** - 特效组管理、特效选择、时间设置
11. **更多渲染设置** - 光照、阴影、后期处理、雾效、环境光遮蔽

### 阶段 4: 资源和时间轴优化（2-3天）
12. **资源包功能强化** - 进度条、已加载资源显示、选择性导出
13. **时间轴拖放优化** - 场景片段连续排列、支持空白间隔
14. **新的渲染触发机制** - 统一渲染触发逻辑，确保所有改动立即渲染

### 阶段 5: 场景渲染和导出（2-3天）
15. **场景混合渲染** - 支持纯色+GLB+图片混合
16. **项目渲染导出** - 实现真实的视频/GIF导出功能

### 额外建议的功能：
- **动画曲线编辑器** - 在右侧面板添加关键帧曲线编辑
- **材质编辑器** - 更详细的材质属性调整
- **物理设置** - 布料、头发物理模拟开关
- **音频可视化** - 音乐波形显示
- **多摄像机切换** - 支持多个摄像机机位
- **绿幕/蓝幕功能** - 便于后期合成

## 技术要点：
- 所有输入框使用 onChange + onBlur 双模式确保实时更新
- 使用统一的 forceRender() 方法触发3D渲染
- 特效系统使用 Three.js 的 EffectComposer
- 视频导出使用 MediaRecorder API 或 FFmpeg.js

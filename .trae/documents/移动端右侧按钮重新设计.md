## 移动端右侧按钮重新设计方案

### 设计思路
- **精简外观**: 移动端只显示图标按钮，更小巧
- **功能完整**: 所有功能都保留，通过展开菜单访问
- **悬浮设计**: 按钮悬浮在屏幕右侧，不占用空间
- **展开面板**: 点击后展开完整功能面板

### 移动端专属设计

#### 1. 收起状态（默认）
- 显示一个圆形悬浮按钮在右下角
- 按钮带脉冲动画吸引注意
- 显示当前角色头像缩略图

#### 2. 展开状态
- 从右侧滑出精简面板
- 显示5个核心功能图标（大按钮，易点击）
- 底部显示角色信息

#### 3. 核心功能按钮（5个）
```
┌─────────────────┐
│  🎭  📸  ⭐   │  ← 动作、拍照、收藏
│                 │
│  🎨  ⚙️        │  ← 姿势、设置
│                 │
│  [角色信息]      │  ← 底部信息栏
└─────────────────┘
```

- **🎭 动作**: 打开动作面板
- **📸 拍照**: 快速截图
- **⭐ 收藏**: 展开收藏动作列表
- **🎨 姿势**: 打开姿势面板
- **⚙️ 设置**: 打开设置菜单

#### 4. 交互优化
- 按钮大小 56x56px（易点击）
- 间距 16px（防误触）
- 点击有水波纹反馈
- 支持手势滑动展开/收起

### 视觉风格
- 圆形按钮，渐变背景
- 悬浮阴影效果
- 二次元配色（粉蓝渐变）
- 展开时背景模糊

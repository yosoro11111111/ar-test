## 混合方案C - 简单实用设计

### 核心原则
- **简单**：去掉所有复杂手势，只保留双指缩放
- **实用**：高频功能一键直达
- **清晰**：界面不拥挤，功能分区明确

---

### 布局设计

```
┌─────────────────────────────────────┐
│                                     │
│           3D 场景区域               │
│                                     │
│    (双指 pinch 放大/缩小)           │
│                                     │
├─────────────────────────────────────┤
│  🎭动作  📸拍照  ⭐收藏  🎨姿势  ⚙️  │  ← 底部固定 Dock
└─────────────────────────────────────┘
      ↑
   点击展开动作面板
```

---

### 具体实现

**1. 底部 Dock 栏（5个按钮）**
```
位置：fixed bottom: 0
高度：64px
背景：半透明毛玻璃
```

按钮功能：
| 图标 | 功能 | 点击效果 |
|------|------|----------|
| 🎭 | 动作 | 展开动作选择面板 |
| 📸 | 拍照 | 直接截图保存 |
| ⭐ | 收藏 | 展开收藏列表 |
| 🎨 | 姿势 | 展开姿势面板 |
| ⚙️ | 更多 | 展开设置菜单 |

**2. 动作选择面板**
```
展开方式：从底部滑上
高度：50% 屏幕
内容：分类标签 + 动作网格
关闭：点击空白处或下滑
```

**3. 场景交互**
- ✅ 双指 pinch：放大/缩小
- ✅ 单指拖动：旋转视角
- ✅ 点击角色：选中/触发动作
- ❌ 删除所有其他手势

**4. 设置菜单（简化）**
```
只保留核心选项：
- 画质选择（高/中/低）
- 显示/隐藏网格
- 重置视角
- 关于
```

---

### 优势

1. **单手操作**：底部按钮拇指可轻松触及
2. **零学习成本**：图标直观，点击即反馈
3. **不遮挡场景**：Dock 栏半透明，沉浸感强
4. **快速访问**：5个核心功能 1 步直达

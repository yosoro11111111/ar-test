基于你的需求，我设计了以下优化方案：

## 1. 时间轴界面重构

### 新的轨道层级结构

```
┌─────────────────────────────────────┐
│ 场景轴 (Scene)                       │ ← 唯一，可折叠
├─────────────────────────────────────┤
│ 摄像机轨道 (Camera)                  │ ← 唯一，点击按钮添加
├─────────────────────────────────────┤
│ 👤 第一个人物名                     │ ← 分组标题（可右键删除）
│    ├─ 动作轴                        │ ← 自动识别拖入的动作
│    └─ 道具轴                        │ ← 自动识别拖入的道具
├─────────────────────────────────────┤
│ 👤 第二个人物名                     │ ← 新人物添加在最下面
│    ├─ 动作轴
│    └─ 道具轴
├─────────────────────────────────────┤
│ 🎵 音乐轨道                         │ ← 唯一
└─────────────────────────────────────┘
```

### 数据结构变更

```javascript
// 角色组结构
{
  id: 'char_group_xxx',
  type: 'character_group',  // 分组类型
  characterId: 'char_xxx',  // 关联的角色ID
  name: '人物名',
  isGroupHeader: true,      // 标记为分组标题
  children: [               // 子轨道
    { type: 'motion', name: '动作' },
    { type: 'prop', name: '道具' }
  ]
}
```

## 2. 摄像机按钮（替代拖放）

### 实现方案

**中央预览区工具栏添加摄像机按钮：**

```
┌─────────────────────────────────────────┐
│ 🖱️ ✋ 🔄 🔍  [📷 添加摄像机]  透视 ▼     │
└─────────────────────────────────────────┘
```

**流程：**

1. 用户在预览区选择一个人物
2. 点击"添加摄像机"按钮
3. 自动创建摄像机轨道（场景轨道下方）
4. 摄像机自动对准选中的角色

***

## 3. 拖放自动识别轨道

### 新的拖放逻辑

**拖到人物名区域：**

```
拖入动作 → 自动放入该人物的动作轴
拖入道具 → 自动放入该人物的道具轴
拖入表情 → 自动放入该人物的表情轴（如有）
```

**拖到空白区域：**

```
拖入角色 → 创建新人物组（在最下方）
拖入场景 → 放入场景轴
拖入音乐 → 放入音乐轴
```

## 5. 人物名右键删除

### 右键菜单

右键点击人物名分组标题：

```
┌─────────────────┐
│ 🗑️ 删除人物     │
│ 📋 复制人物     │
│ ─────────────── │
│ 👁️ 显示/隐藏    │
└─────────────────┘
```

删除时同时删除：

* 该人物的所有轨道

* 该人物的所有片段

* 场景中该人物的实例

## 8. 修复预览功能

### 问题分析

当前预览功能可能存在的问题：

1. 播放时角色动作没有更新
2. 摄像机位置没有根据时间轴变化
3. 场景没有切换

### 修复方案

**实时渲染循环：**

```javascript
// 每帧更新
function updateFrame(time) {
  // 1. 更新场景
  updateScene(time)
  
  // 2. 更新角色动作
  updateCharacterAnimations(time)
  
  // 3. 更新摄像机
  updateCamera(time)
  
  // 4. 渲染
  render()
}
```

**播放控制修复：**

* 修复播放/暂停状态

* 修复时间跳转

* 修复循环播放

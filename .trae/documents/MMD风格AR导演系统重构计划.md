## 重构目标
打造一个专业级MMD风格AR导演系统，支持多场景地图、角色动作编排、真实位移计算

## 核心功能规划

### 2. 弹窗系统

#### 角色选择弹窗（参考AR模式）
- 网格布局显示角色缩略图
- 点击选择，支持多选
- 从人物库加载已保存角色
- 实时预览角色形象

#### 动作选择弹窗
- 分类浏览（舞蹈/行走/表情等）
- 搜索功能
- 预览动画
- 点击添加到时间轴

#### 场景选择弹窗（地图模式）
- 2D地图视图显示所有场景位置
- 支持框选多个场景
- 显示场景连线（移动路径）
- 时间轴上显示场景切换点

### 3. 时间轴系统重构

#### 多轨道类型
| 轨道 | 功能 |
|------|------|
| 角色轨道 | 每个角色独立轨道，包含动作/位置/旋转 |
| 场景轨道 | 场景切换，支持地图位置移动 |
| 特效轨道 | 粒子特效、滤镜效果 |
| 相机轨道 | 相机移动和切换 |

#### 操作功能
- 拖拽调整时间位置
- 拉伸调整持续时间
- 右键菜单（复制/粘贴/删除）
- 缩放时间轴（10s-5min范围）
- 多选批量操作

### 4. AR地图定位系统

#### 核心概念
- 每个场景 = 地图上的一个坐标点
- 角色可以在场景间移动
- 真实位移 = 场景A位置 → 场景B位置

#### 数据结构
```javascript
scene = {
  id: "scene_xxx",
  name: "客厅",
  position: { x: 0, y: 0, z: 0 },     // AR世界坐标
  rotation: { x: 0, y: 0, z: 0 },
  size: { width: 5, height: 3 },
  thumbnail: "...",
  type: "ar" | "image"
}

timelineClip = {
  id: "clip_xxx",
  type: "action" | "scene" | "move" | "effect",
  targetId: "char_xxx" | "scene_xxx",
  startTime: 0,
  duration: 5,
  data: {
    // 动作: { actionId, loop }
    // 场景: { sceneId, position, rotation }
    // 移动: { fromSceneId, toSceneId, path }
    // 特效: { effectId, params }
  }
}
```

### 5. 预览系统

#### 默认隐藏预览
- 点击"预览"按钮才显示3D画面
- 节省屏幕空间，专注时间轴编辑

#### 预览模式
- 播放时实时渲染
- 显示角色、场景、特效
- 相机跟随角色移动
- 支持暂停和逐帧前进

### 6. 导出系统

#### 计算真实位置
- 根据场景坐标计算角色位移
- 导出包含位置信息的动画数据
- 支持视频/GIF/数据导出

# AR Director - 产品需求文档 (PRD)

## 产品概述

**产品名称**: AR Director (AR导演)
**产品定位**: 手机端AR视频制作工具
**目标用户**: 短视频创作者、Vlogger、AR爱好者
**核心价值**: 让普通用户用手机就能制作专业级AR视频

---

## 一、功能架构

```
AR Director
├── 场景录制模块 (Scene Capture)
│   ├── 环境扫描
│   ├── 视频录制
│   └── 场景保存
├── 时间轴编辑模块 (Timeline Editor)
│   ├── 多角色管理
│   ├── 动作编排
│   ├── 相机运动
│   └── 特效添加
└── 渲染导出模块 (Render Export)
    ├── 视频渲染
    ├── GIF导出
    └── 图片序列
```

## 二、用户流程

### 2.1 主流程

```
[启动APP]
    ↓
[选择工作模式]
    ├─ 新建项目 → [场景录制] → [时间轴编辑] → [渲染导出]
    ├─ 打开项目 → [加载已有项目] → [继续编辑]
    └─ 场景库 → [选择预设场景] → [直接编辑]
```

### 2.2 详细流程

#### 场景录制流程
```
1. 用户点击"新建项目"
2. 进入AR相机界面
3. 扫描环境（自动检测平面）
4. 点击"开始录制"
5. 用户移动手机扫描周围环境
6. 点击"停止录制"
7. 预览录制的场景
8. 保存或重新录制
9. 进入时间轴编辑器
```

#### 时间轴编辑流程
```
1. 显示已录制的场景背景
2. 用户点击"添加角色"
3. 选择VRM模型文件
4. 在场景中点击放置位置
5. 为角色添加动作
   - 从动作库选择
   - 拖动到时间轴
   - 调整时机和时长
6. 添加更多角色（最多5个）
7. 设置相机运动轨迹
8. 添加特效
9. 预览播放
10. 保存项目
```

#### 渲染导出流程
```
1. 用户点击"导出"
2. 选择导出格式（视频/GIF/图片）
3. 设置参数（分辨率/帧率/质量）
4. 点击"开始渲染"
5. 显示渲染进度
6. 渲染完成，预览结果
7. 保存到相册或分享
```

### 5.2 关键技术点

#### WebXR录制方案
```javascript
// 双渲染模式：同时渲染到XR设备和屏幕
function render() {
  // 1. 渲染到XR设备
  gl.bindFramebuffer(gl.FRAMEBUFFER, xrFramebuffer);
  renderer.render(scene, camera);
  
  // 2. 渲染到屏幕（用于录制）
  gl.bindFramebuffer(gl.FRAMEBUFFER, null);
  renderer.render(scene, camera);
}
```

#### 多角色动画同步
```javascript
// 每个角色独立的mixer
class MultiCharacterManager {
  characters = new Map();
  
  update(deltaTime) {
    this.characters.forEach((char, id) => {
      // 根据距离优化更新频率
      const distance = char.position.distanceTo(camera.position);
      if (distance > 10 && frameCount % 2 !== 0) return;
      
      char.mixer.update(deltaTime);
      char.vrm.update(deltaTime);
    });
  }
}
```

#### 离线渲染
```javascript
// 逐帧渲染，不依赖实时性能
async function offlineRender(timeline, duration, fps) {
  const frames = [];
  const totalFrames = duration * fps;
  
  for (let i = 0; i < totalFrames; i++) {
    const time = i / fps;
    
    // 更新场景状态
    updateSceneAtTime(timeline, time);
    
    // 渲染帧
    renderer.render(scene, camera);
    
    // 读取像素数据
    const pixels = readPixels();
    frames.push(pixels);
    
    // 更新进度
    onProgress(i / totalFrames);
  }
  
  return encodeVideo(frames, fps);
}
```

3. `MotionGroupEditor.jsx` - 动作组编辑器

### 数据结构
```javascript
// 道具绑定
propBinding: {
  targetBone: 'head', // 绑定骨骼
  followMotion: true, // 跟随动作
  offset: {x, y, z},  // 位置偏移
  rotation: {x, y, z} // 旋转偏移
}

// 动作组
motionGroup: {
  id: 'group_001',
  name: '日常动作组',
  category: '日常',
  motions: [
    {motionId, startTime, duration}
  ]
}
```
